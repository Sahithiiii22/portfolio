# Sahithi Tarigoppula — Data Scientist & AI/ML Engineer Portfolio

A modern, high-impact developer portfolio website for **Sahithi Tarigoppula**, an aspiring **Data Scientist**, **Machine Learning Engineer**, and **AI/ML Specialist** (B.Tech in Computer Science and Engineering - Data Science, **9.02/10 CGPA** at Vignana Bharathi Institute of Technology).

Inspired by the editorial brutalist design aesthetic of [Akhilan's Portfolio](https://akhilan9.github.io/Portfolio/):
- **Warm Editorial Color Scheme**: `#e8e6df` warm parchment/paper canvas paired with bold `#000000` deep black contrast sections.
- **Custom Magnetic Difference Cursor**: Interactive spring cursor that inverts across backgrounds (`mix-blend-mode: difference`) and expands smoothly over interactive elements.
- **Clean Modern Typography**: High-contrast, crisp typography powered by Google Fonts `Inter` (weights 400, 500, 600, 700) paired with `JetBrains Mono` for code elements.
- **Pure Native Tech Stack**: 100% HTML5, CSS3, and Vanilla JavaScript with zero external frameworks or paid dependencies.

## 🌐 Deploying to GitHub Pages (Free)

1. **Initialize Git and commit**:
   ```bash
   git init
   git add .
   git commit -m "Build Sahithi Tarigoppula portfolio: Data Science & AI/ML"
   ```

2. **Add remote and push to GitHub**:
   ```bash
   git remote add origin https://github.com/Sahithiiii22/portfolio.git
   git branch -M main
   git push -u origin main
   ```

3. **Enable GitHub Pages**:
   - Navigate to your repository on GitHub: `https://github.com/Sahithiiii22/portfolio/settings`
   - In the left sidebar, click **Pages**
   - Under **Build and deployment**, select **Deploy from a branch**
   - Choose branch: **main**, folder: **/ (root)**
   - Click **Save**
   - Your website will be live in 1–2 minutes at `https://Sahithiiii22.github.io/portfolio/`
